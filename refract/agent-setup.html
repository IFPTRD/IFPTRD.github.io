Set up a Microsoft 365 Copilot agent for Refract

Use this generic configuration to turn source documents into the JSON expected by the Refract guide builder. No content from any other guide is included.

1. Create the agent

  1. In Microsoft 365 Copilot, open the available agent-building experience (often Create an agent). Availability and naming depend on your tenant.
  2. Name the agent Refract — Guide Content Architect.
  3. Copy the contents of agent instructions into the agent's Instructions field. If there is a character limit, retain the rules about sources, schema, factual accuracy and JSON-only output.
  4. Use content-example.json as the structural reference. Attach it as an agent knowledge file if supported, or supply it with each conversation. It contains only generic example content.
  5. Save, test with harmless sample documents, then share the agent under your tenant's approved governance process.

2. Generate a guide

  1. Provide the specific source document(s) to Copilot inside your approved Microsoft 365 environment.
  2. Identify the audience and what they need to do with the guide.
  3. Ask the agent for Refract-compatible JSON only.
  4. Copy the response or save it as a .json file.
  5. Open Refract, paste or import the JSON, select Validate & Preview, review thoroughly, then export the standalone HTML.

3. Suggested quality gate

Review source fidelity, information classification, links, decisions/authorities, page hierarchy, terminology, print layout and mobile usability before distribution. Treat Copilot output as a draft.

Important: This is a publicly hosted static builder. It does not upload content to the GitHub server, but only use source material approved for your environment and never publish generated guides containing protected information on public GitHub Pages. The Microsoft 365 agent is configured separately inside your organization.
