Set up the Refract Copilot skill

Download Refract Skill (.zip)

Upload this ZIP directly under Configure → Skills → Add in Microsoft 365 Copilot Agent Builder. Do not extract it.

Refract uses a reusable skill to convert your own documents into structured JSON. The skill contains its schema, examples and a format validator; no other project's content is included.

1. Install the skill

  1. Download the Refract skill ZIP directly from this page. Keep the ZIP intact.
  2. In Microsoft 365 Copilot Agent Builder, open your Refract agent and go to Configure → Skills → Add.
  3. Upload the complete ZIP, with SKILL.md inside it. Confirm the refract-guide-authoring skill appears.
  4. Replace your old Instructions text with the short skill-based agent instructions. Remove the previous long prompt and starter-message material.
  5. Save the agent. No example JSON web-search source is required.

2. Generate a guide

  1. Open the agent's Try it conversation; attach a short, appropriately classified DOCX or select a file accessible to the agent.
  2. Send: Use the Refract guide-authoring skill to turn the attached document into a concise guide. Return complete valid Refract JSON only.
  3. Download the produced JSON if supported, or copy the raw JSON without Markdown fences.
  4. Open Refract, import or paste JSON, choose Validate & Preview, and review the output before exporting HTML.

3. Troubleshooting

If the agent repeats “Attach or select the source documents,” the previous Instructions are probably still active. Replace them with the short skill-based instructions, and test in Try it (not in the Configure description field).

If it cannot read a DOCX, first ask the agent to summarize one sentence from that file. That helps distinguish attachment-access problems from JSON-generation problems.

If Refract reports invalid JSON, have the agent run its bundled scripts/validate_refract.py when script execution is available. Refract also checks that blocks use the correct shapes (e.g., checks contain title/detail objects and notes use a label field).

4. Review and distribution

Information handling: Refract's builder runs in the browser and does not upload user JSON to GitHub. The GitHub Pages code is public, however. Handle source documents and exported guides only through authorized organizational channels, with factual review and approvals before distribution.
