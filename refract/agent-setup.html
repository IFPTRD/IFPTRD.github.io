Refract — Microsoft 365 Copilot HTML Generator

Convert authorized source documents into a complete, interactive HTML guide that can be edited later in Refract Studio. The generator uses the same fixed design template as Refract. It does not require copying JSON into the builder.

Download the HTML generator skill

Download Refract HTML Generator v6.2 (.zip)

The ZIP contains SKILL.md, the adaptive high-contrast Refract template, schema, generic example, source-coverage guidance, an additional binder-completeness checker, JSON validator, and offline Python renderer. The template supports editable governance diagrams and timelines, plus verified readable text colours and corrected hero-heading contrast. No source documents from other projects are included.

1. Configure the agent

  1. Open your existing agent in Microsoft 365 Copilot Agent Builder under Configure.
  2. Under Skills, remove or replace the previous Refract skill. Upload the new v6.2 ZIP intact using Add.
  3. Replace all earlier agent Instructions with the latest Refract agent instructions. Do not place sample prompts in the Instructions field.
  4. Save the agent and open Try it in a fresh conversation. Make sure its document access and Code Interpreter/file generation capabilities are available in your tenant.

2. Create a guide

  1. Attach or select the document(s) within your approved Microsoft 365 environment. Attaching a document is enough to initiate guide creation automatically when the agent can access it. You do not need to type a prompt.
  2. Optional: specify the audience or priorities. By default, Refract aims to replace the source document faithfully with clearer navigation and formatting, not turn it into an abbreviated companion guide. It should retain agendas, issue briefs, annexes and distinct factual content.
  3. Download the generated .html file from the Copilot conversation and inspect it in a browser.
  4. To revise: open Refract Studio, choose Import HTML, edit pages or sections, and export the revised HTML.

3. Troubleshooting

If Copilot generates only JSON, drops large sections, adds invented intervention advice, or narrates a plan, verify the old Instructions and skill were replaced with v6.2 and that Code Interpreter is available. The renderer must be executed with the packaged template; Copilot should not independently write HTML/CSS/JavaScript.

For a long e-binder, ask the agent to review its source-inventory.json against the original agendas, briefing notes and annexes and run scripts/check_coverage.py. If the skill reports a validation error, ask the agent to repair its intermediate Refract JSON and rerun scripts/render_refract.py. If your tenant cannot produce downloadable HTML, the skill explicitly falls back to Refract JSON rather than claiming successful file generation.

If a guide does not import as editable, hard-refresh Refract Studio to load the v5 block support. Verify it was generated by Refract and still contains script#guide-data. Refract Studio can convert other HTML approximately, but exact editing requires embedded guide data.

4. Information handling

Keep source documents and generated guides in approved channels. The Refract software and skill ZIP are public on GitHub Pages. The agent should process your documents in the approved Microsoft 365 environment; do not upload generated guides containing restricted material to a public repository. Check all substantive content and links before distribution.
